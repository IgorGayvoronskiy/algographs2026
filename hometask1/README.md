# hometask1

## Идея решения
Задача NP-трудна, поэтому используется эвристика. Граф раз за разом разбивается на компоненты сильной связности алгоритмом Косарайю, вершины из одиночных компонент на циклах не лежат и отбрасываются. Среди оставшихся жадно выбираются вершины с максимальным произведением входящей и исходящей степени внутри своей компоненты, и они добавляются в ответ. Пока потенциально лежащих на цикле вершин много, за раунд берётся батч, чтобы не пересчитывать компоненты слишком часто; когда их остаётся не больше 2000, берётся по одной. Жадность заканчивается, когда нетривиальных компонент не осталось, то есть граф без выбранных вершин ацикличен.

Затем ответ чистится: каждая выбранная вершина по очереди пробно возвращается в граф, и если она не лежит ни на каком цикле, она удаляется из ответа. Первый запуск детерминированный. После него жадность повторяется со случайным шумом в ключе выбора, а чистка идёт в случайном порядке; лучший найденный ответ запоминается. Перезапуски идут до исчерпания их лимита, который зависит от размера графа или до получения SIGTERM, после чего выводится лучший допустимый ответ.

## Сборка и запуск

Сборка (нужен компилятор с поддержкой C++11 или новее): выполните следующую команду из директории `hometask1`.

```
g++ -O2 -o solution/solution solution/solution.cpp
```

Запуск:

```
./solution/solution < tests/tiny10.gr > output.txt
```
